## 使用约定

- **命名规范**：建议实验报告文件命名为 `第xx周_实验名称.md` 或 `.pdf`。
- **提交频率**：每完成一周实验即提交一次，保持 `Commit` 信息清晰可回溯。
- **隐私注意**：请勿在仓库中上传包含个人敏感信息（如密钥、密码、身份证号）的文件。
